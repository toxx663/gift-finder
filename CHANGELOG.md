# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.1.0] - 2026-11-18

### Added

- Direct buy links for every pick: the product's own page on the Amazon storefront or another shop that delivers to the user's country, with no affiliate tags.
- Step 7, "Finalise the chosen item": compatibility, variant, what is not in the box, timing and returns.
- Refinement questions now check what the recipient already owns (for example an instant camera before recommending a photo printer).

## [1.0.0] - 2026-11-18

### Added

- Initial release of the `gift-finder` skill.
- Guided interview: recipient, interests, budget, destination country.
- Category shortlist of four to six gift types with a "none of these" loop.
- Category-specific refinement questions.
- Web research step with cross-checked sources and verified prices.
- Three-pick result format: best overall, best value, wildcard.
- Claude Code plugin and marketplace manifests.
